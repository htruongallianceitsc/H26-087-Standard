# V2.1 Stabilization Review

## Mục tiêu

Ổn định catalog v2 trước khi mở rộng schema v3 hoặc viết thêm standard mới.

## Thay đổi chính

- Loại bỏ 2 bản sao schema v1 của `STD-TEST` và `STD-PERF-TEST` khỏi `01-governance-delivery`; bản canonical nằm tại nhóm QA.
- Validator phát hiện duplicate `code` thay vì âm thầm ghi đè khi nạp JSON.
- Sửa applicability cho React/Next/Flutter technology standards.
- Gỡ ràng buộc React khỏi toàn bộ `STD-WEB-*` để platform standards có thể dùng cho Vue/Angular/stack web khác.
- Chuyển 12 `CAP-*` sang feature-gated applicability.
- `STD-REQ` và `STD-TEST` trở thành baseline ngầm định của resolver, giảm dependency boilerplate.
- Bổ sung hai profile automatic để regression-test chế độ không có `selected_standards`.
- JSON standard/capability trở thành source of truth; manifest, STRUCTURE và JS catalog được sinh từ tool.
- Thêm content linter với baseline debt để ngăn skeleton/boilerplate tăng thêm; strict mode dùng để theo dõi mục tiêu Phase 1.
- Thêm GitHub Actions quality gate.

## Chưa làm trong v2.1

- Chưa chuyển sang schema v3/component-based profile để tránh breaking change.
- Chưa viết lại toàn bộ 56 skeleton và 79 semi-template standard. Đây là Phase 1 tiếp theo.
- Không thể khôi phục nội dung v2 cũ từ file ZIP vì artifact không chứa `.git`; cần lịch sử Git hoặc bản backup nếu muốn phục hồi nguyên văn thay vì viết lại.
